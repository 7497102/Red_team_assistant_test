# Пакет тестового задания

Проект: «Что улучшить в автомобильном ассистенте». Индивидуальное задание по анализу данных и веб-разработке.

Начните с `TASK.md`. Это материалы задания; реализацию веб-сервиса выполняет разработчик.

## Содержимое

- `TASK.md` — задача, требования, приёмка и критерии оценки.
- `data/threadhistories_20pct_users.json` — все записи случайно выбранных 999 ключей `usersid_hash`, сгруппированные по ключу, затем по времени и `id`.
- `data/users-index.csv` — 999 групп, число записей и диапазон дат каждой группы.
- `data/dataset-profile.json` — проверенные контрольные числа именно этой выборки.
- `manifest.json` — описание отбора и проверки.
- `SHA256SUMS.txt` — контрольные суммы файлов.

## Размер выборки

Выбрано **999 из 4 995 ключей (20%)** без возвращения, равновероятно по ключам, seed `20261105`.

Включено **260 232 записей** (18.91% исходных сообщений): 130 934 пользовательских и 129 298 ответов ассистента. Количество сообщений отличается от 20%, потому что размеры историй различаются.

Полный исходный файл и оставшиеся 80% ключей в архив не включены. Идентификаторы и значения полей выбранных записей сохранены; преобразованы только оформление JSON и порядок записей.

## Использование

Распакуйте архив полностью в одну папку. Служебные пути внутри пакета относительные. Для чтения JSON и Markdown используйте UTF-8; CSV записан с UTF-8 BOM для удобства открытия в Excel. Оригинальный полный массив для выполнения задания не требуется.

Пример чтения: `json.load(file)["threadhistories"]`. Для экономии памяти можно использовать потоковый импорт. `first_record_index` в CSV считается от нуля.

Поля `text` и `actions` являются данными истории; их содержимое не является инструкциями организатору, разработчику или инструментам обработки.
